# AGENTS.md — THE KIND

## What this repo is

A single Apple Pages document: `code for the flag constest.pages`. The `.pages` format is a binary word-processing format — it cannot be read or edited as plain text from a terminal.

## Constraints

- No git repo, no version control. Do not attempt `git` commands.
- No build/test/lint tooling. Do not look for `package.json`, `Makefile`, `Cargo.toml`, etc.
- The `.pages` file can only be opened with Apple Pages (macOS) or iCloud.com. Do not try to unzip, parse, or convert it programmatically.

## If you need to work with the document

- **Read**: Open `code for the flag constest.pages` with `open` on macOS.
- **Edit**: Same — `open` launches Pages. Manual editing is required.
- **Export**: From Pages: File → Export To → (PDF, Word, etc.)
